# ADR-0004 · 改为「用户自持凭据 + 开放许可资源联网可达」

- **状态**：已接受
- **日期**：2026-09-16
- **决策人**：项目负责人（R1）
- **相关**：`docs/01` **N14**（用户自持凭据）· **N15**（外传告知）· **N3**（已废弃）· **N4**（口径收窄）· F10 · F16 · `docs/02` §1.2 §1.3 §4.2.1 §6.3 · ADR-0001（§v2 重新评估被本决策证伪）· ADR-0003

---

## 背景

v2 建仓时的需求口径是 **N3「数据不出校（可本地 / 局域网运行）」+ N4 的"离线可跑"**，两条都是 MUST。整套设计建立在这个前提上：

- 检索与判定默认本地，**无 KEY 时自动降级**（甚至有一条"模板填充"的离线生成路径）；
- L1 语料"仅校内"，`§6` 的可用性验收写的是"**无 Key、无网、无安装可完整演示** / **断网演示**"；
- 盲测拆法的理由里引用了"离线、无密钥基础设施的前提下，门禁无法从仓库外取题"。

2026-09-16，需求方明确口径：**产品不是"离线或局域网可跑"，而是"允许用户自接 key 的 agent 助手"，并且一些学习资源联网可达**。

这推翻了两条 MUST，因此不是口径澄清，而是**需求层反转**。

---

## 决策

### 1. 凭据由用户自持（N14）

- 允许用户用**自己的**模型凭据接入；系统**不内置、不共享、不外传**凭据。
- **凭据只存浏览器本地**（`localStorage`），**随请求携带**（请求头 `X-Model-Key`），**服务端不代为持有**。
- **硬约束**：凭据**不得落日志、不得进审计 `detail`、不得进错误信息、不得进 L2 表**（`docs/02 §1.4` 的 **R-J**）。
- **无凭据 ⇒ 答疑不可用**（503 `model_unavailable`）；**判定 / 错题本 / 进度 / 知识图谱照常可用**。
- 答疑使用 `POST + fetch 流`（`EventSource` 不能带自定义头）。

### 2. 学习资源只取开放许可、预抓后缓存（F10）

- **只抓开放许可资源**（MIT OCW / OpenStax / 可汗学院等）；条目必须带 `license` / `source_url` / `fetched_at`，缺一即资产错误。
- **抓取在预抓阶段完成，运行期只读缓存** —— 不做运行期实时抓取。
- 出处仍用 **`cite_id`**；缓存缺失时如实说明"出处暂不可用"，**不得编造章节号**。

### 3. 必须告知外传（N15）

- **显著告知**"提问会被发送到第三方模型服务"（首次使用 + 设置页随时可查）。
- 它是 **N2 诚实**的组成部分，不是附加项。

### 4. 如实声明删除权的边界（F16）

- 删除权覆盖**本机全部数据**；**第三方已收到的请求删不掉** —— 该边界须与 N15 一并告知用户。

## 后果

**正面**

- 不再需要内置模型凭据，**额度和责任归用户**；项目不承担模型费用，也不承担"代学生付费"的运营问题。
- 教学资源可用面变大（开放许可资源比"本校教材电子版"容易拿到，且版权干净）。
- 判定链路本来就不依赖模型（F4），因此**"无凭据也能跑完判定 / 错题本 / 知识图谱"**天然成立 —— 降级演示有真实内容。

**代价（必须承认）**

1. ★ **学生提问原文离开本机成为常态**。`N6`（化名、不采集学号姓名）因此**从"锦上添花"变成"必须严格执行"**：出去的内容带不带真实身份，性质完全不同。
2. ★ **删除权有删不到的部分**（第三方已收到的请求）。已写进 F16 的边界句。
3. ★ **现场风险**：ADR-0001 当初的动机之一就是"**答辩现场网络不可控**"。本决策**主动放弃了"断网也能完整演示"这个保险**。缓解：`§6` 的可用性验收拆为**完整演示**与**降级演示**两条，且**如实承认降级演示不覆盖答疑**。
4. **凭据是一个新的泄露面**：只存浏览器 + 随请求传 ⇒ 任何一处"顺手把整个请求打日志"都会泄露用户额度（已由 R-J 兜底）。
5. **`N4` 的承诺变弱**：从"离线可跑"降为"免构建、零 npm、零安装"。

## 被否决的备选方案

| 方案 | 为什么不选 |
|---|---|
| **部署方共享一个 key**（管理员配，全体学生用） | 最省事、无凭据泄露面，但**这不是"用户自接"**：额度与责任集中，学生不能用自己的额度。**可作为将来"自接优先 + 回退共享"的扩展**（未采纳，因为它要求两条路径都测） |
| **服务端按用户加密存储凭据** | 一次配置处处可用，但**凭据成为新的高敏感数据**（泄露 = 用户额度被盗），要引入加密与密钥管理面 —— 而本仓在审计盐化那条上刚以"为本地部署引入密钥管理面不划算"否决过同类方案，口径应一致。**且 F16 的删除范围要再加一张表** |
| **保留 mock（旧仓 `llm_provider = "auto"`）** | 旧仓用它保证"零配置可跑"，但它产出的是**假答案** —— 与 **N2 诚实**直接冲突。v2 只在**测试**里注入假 provider，**不提供产品级 mock** |
| **保留"模板填充"作为离线降级路径** | 该路径的触发条件是"无 KEY"，而新口径下"无凭据"是**用户没配**（可修），不是"环境不允许"。继续保留它等于**在用户可修的问题上悄悄降级**，且会让"答疑不可用"这条清晰语义变模糊。**整条作废** |
| **联网实时检索（含校内教材在线版）** | 网页会变 ⇒ `cite_id` 不可复核，且"检索命中带出处"的评测**不稳定**。改为**预抓 + 缓存** |
| **维持 N3 不动、只增 N14** | 那会让文档同时声称"数据不出校"与"数据会外传"，两者直接矛盾 —— 而这类"同词反义"的边界在本仓已被记为反复出现的缺陷模式（见 `docs/02 §6.1` 的"班级统计"一例） |

## 可逆性

| 决策 | 可逆性 |
|---|---|
| 用户自持凭据 | **高**：契约里凭据是**请求级的可选输入**，将来改"部署方共享"只是换一个来源，调用链不变 |
| 无凭据 ⇒ 答疑不可用 | **中**：若将来要加"回退共享 key"，它是**新增一条路径**而不是改写现有语义 |
| 只取开放许可 + 缓存 | **高**：缓存目录与元数据（`license` / `source_url` / `fetched_at`）与来源无关 |
| **数据会外传这件事** | **不可逆**（已经发生的事实）。因此 N15 的告知与 F16 的边界**不可撤回**，只能补充说明 |
